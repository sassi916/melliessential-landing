## 🚀 Deploy
1. Push to GitHub (already done)
2. Import the repo on [vercel.com](https://vercel.com)
3. Click **Deploy** — site is live in ~30 seconds
4. (Optional) Connect a custom domain like `melliessential.com.ng`
